# XianYaoZhi

《仙妖志》是一个融合计算民俗学与数字人文学的开源项目。我们尝试借助自然语言处理、知识图谱、网络分析与生成式 AI，对散落于古籍、民间传说、志怪小说中的中国神话角色进行系统化整理、结构化建模与跨文本分析。

这个项目关注的不只是“收集资料”，更是一个关于理解与再现的问题：当神话角色被放入可计算的知识结构中，AI 能否识别其叙事功能、形象演变、关系网络与文化隐喻，并在此基础上生成更接近中国神话语境的解释与表达。

## 项目愿景

《仙妖志》希望构建一套面向中国神话角色研究的开放基础设施，包括：

- 一个可持续扩展的神话角色数据库
- 一个兼具文本证据、语义关系与叙事标签的知识图谱
- 一套适用于古籍与志怪文本的分析流程
- 一组可用于研究、创作与教育传播的 AI 工具与数据资产

我们希望它既能服务学术研究，也能服务公众理解，让“仙、妖、神、怪”不再只是零散的文化符号，而成为能够被检索、比较、关联和解释的知识对象。

## 研究对象

项目主要关注中国传统叙事体系中的超自然角色与相关文化实体，包括但不限于：

- 仙：得道者、隐逸仙人、飞升者等
- 妖：草木成精、器物成怪、兽类化形等
- 神：地方神、山川神、司职神灵、祭祀神明等
- 怪：异人、异兽、异象、混合型叙事角色等

除角色本体外，项目也关注与其相关的以下信息：

- 出处文本与版本信息
- 别名、异名、称谓变化
- 形象特征与能力描述
- 叙事功能与情节位置
- 与人物、地点、器物、事件之间的关系
- 跨时代、跨文本的演变路径

## 核心方法

《仙妖志》将人文学研究与计算方法结合，形成一套可复用的分析框架。

### 1. 文本整理与语料建设

对古籍、志怪小说、笔记、地方传说等材料进行搜集、清洗、切分与标注，逐步形成可计算语料库。

### 2. 实体识别与知识抽取

从文本中抽取角色、地点、能力、事件、关系等信息，建立结构化字段与证据链，降低神话材料“只可读、不可算”的门槛。

### 3. 知识图谱构建

将角色及其关系组织为可查询、可扩展的图谱结构，用于回答诸如“谁与谁经常共现”“某类妖怪如何演变”“某一角色在不同文本中的定位有何差异”等问题。

### 4. 网络分析与模式发现

利用图分析与统计方法观察神话角色的传播结构、叙事核心、群体聚类与语义相似性，寻找传统阅读不易直接发现的模式。

### 5. 生成式 AI 辅助解释与再现

在有文本依据与知识约束的前提下，探索生成式 AI 对神话角色的摘要、重述、对比、谱系归纳与风格化再表达能力。

## 希望产出的内容

项目的中长期产出可能包括：

- 神话角色结构化数据库
- 角色关系知识图谱
- 标注规范与数据字典
- 语料整理与分析脚本
- 面向研究与公众展示的可视化页面
- 基于知识约束的角色检索、问答与生成工具

## 这个项目想回答的问题

《仙妖志》不仅是资料工程，也是一组研究问题的集合，例如：

- 中国神话中的“仙、妖、神、怪”究竟如何区分，又如何相互转化？
- 同一角色在不同时代、地域与文本中为何会出现形象漂移？
- 神话叙事中高频重复的结构、母题与关系模式是什么？
- 当 AI 学习这些材料时，它理解的是词语表层，还是更深层的叙事逻辑与文化结构？
- 如何让机器生成的神话表达更符合文本证据与传统语境，而不是仅仅“像神话风格”？

## 适用场景

这个项目可以面向多个方向使用：

- 数字人文学与民俗学研究
- 中国神话主题的知识整理与教育传播
- 文学研究中的跨文本角色比较
- 游戏、影视、动画与互动叙事的世界观参考
- 面向中文传统文化语境的 AI 应用实验

## 当前阶段

项目目前处于早期规划与说明完善阶段。现阶段更重要的是明确研究边界、数据结构与方法路线，而不是过早堆叠功能。

后续可以逐步推进为以下几个方向：

1. 建立基础语料清单与来源规范
2. 设计角色数据模型与字段体系
3. 制定标注规则与知识抽取流程
4. 构建首批示例数据与最小知识图谱
5. 开发查询、分析与展示原型

## 项目原则

为了让项目能够长期演进，我们倾向于坚持以下原则：

- 以文本证据为基础，避免脱离语境的过度解释
- 以结构化与可追溯为目标，而不是只做结论性摘要
- 以开放协作为导向，逐步沉淀可复用的数据与方法
- 让 AI 成为研究辅助工具，而不是替代文本判断的黑箱

## 一句话概括

《仙妖志》试图把中国神话中的“仙、妖、神、怪”从零散叙事中重新组织出来，建立一个兼具文本依据、知识结构与 AI 分析能力的开放研究项目。
